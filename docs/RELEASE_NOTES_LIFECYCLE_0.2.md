# lifecycle-reference-v0.2

A new MIT offline lifecycle reference and partner test kit. Connector runtime
remains 0.1.1; no new runtime wheel replaces the existing release.

- Coordinator-owned row inspection, positive calibration and file scans replace
  adapter self-certification. Adapter claims are compared and disagreement fails.
- Registered fixture paths and SQLite DB/WAL/SHM/journal coverage are checked.
- Rastislav's dishonest byte-probe case cannot complete while bytes survive.
- Capability: inspeximus-lifecycle-experimental-v2. Old tags, client imports,
  existing routes and saved schema_v0 envelopes are preserved.
- Fixed pair, machine-readable profile, hashes, expected results and restart-safe
  delivery/replay/conflict runner are included in the partner packet.

Local suite: 165 passed. Both fixed payloads pass JSON Schema validation. The wheel
boundary still excludes research modules. Existing six-platform/version CI must
be checked separately; local tests do not establish cross-platform success.

The real HTTPS operator smoke used different IDs and passed delivery, replay,
HTTP409 conflict, exact stored associations, indexing and natural-language
current-evidence checks. An opaque-ID query did not retrieve the source; the
packet records the text query and this limitation. No live configuration, key,
credential, service or database schema was changed. Only synthetic records added.
